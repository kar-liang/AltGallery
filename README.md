## Adding an app

Three ways, easiest first:

1. **Send a GitHub link to the QQ bot** — message `https://github.com/owner/repo` to the bot in a private chat.
   It probes for a `.ipa` asset, reads the real bundle id and minimum OS version, fetches the icon,
   generates the config and commits — live in about a minute.
2. **Run the script locally** — `python tools/add_app.py owner/repo`
3. **Write the config by hand** — copy `apps/Breeze/config.toml` and change `[github] repo`,
   `bundle_identifier`, and `[versions] asset_pattern`.

## Automation

Two workflows in `.github/workflows/`:

- **`update-sources.yml`** — checks every app for new releases every 6 hours, regenerates and commits
- **`add-app.yml`** — turns a link sent to the bot into a new app entry, end to end
